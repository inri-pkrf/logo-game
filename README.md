# לוגו של אחריות

משחק התאמה של סמלי פיקוד העורף. React + Vite, פריסה ב-Vercel.
אין מסד נתונים ואין התחברות; ההגדרות והשיא נשמרים בדפדפן (localStorage).
האפליקציה אינה תלויה יותר ב-base44.

## הרצה מקומית
```bash
npm install
npm run dev
```

## תמונות
הריצי פעם אחת `node scripts/download-images.mjs` כדי להוריד את התמונות ל-`public/images`
ולעדכן את הכתובות בקוד, ואז עשי commit.
